# 开学军训季，如何防晒、防脱水？

> 更新时间：2026-09-16 (UTC+8)

**点击蓝字，关注我们**
**防晒篇**

又到了开学军训季，虽然不再是炎炎夏日，紫外线的强度仍不可忽视，每年都有很多学生晒伤，皮肤科专家提醒，虽已入秋，还是要做好防晒！

阳光中紫外线根据波长主要分为三种：长波紫外线（UVA,320-400nm)、中波紫外线（UVB,280-320nm）和短波紫外线（UVC,180-280nm)。其中UVC在穿过臭氧层时几乎被完全吸收，到达地面的仅为UVA和UVB，分别约占总量的95％和5%。

紫外线中的UVB作用于表皮层，引起皮肤变红、严重晒伤甚至晒后脱皮；UVA可穿透至真皮浅层，主要引起皮肤变黑、光老化等。

**防晒措施有哪些？**

不被晒到是最好的防晒！平时可以用防晒衣帽、太阳镜、太阳伞等，军训好像办不到，但可以涂防晒霜。

防晒霜又分物理防晒和化学防晒。

物理防晒：主要成分是二氧化钛和氧化锌等无机离子。优点：安全性好，不易过敏

缺点：厚重发白，不自然。

化学防晒：主要是化学合成的脂类。优点：质地轻薄，透明感好；缺点：有一定的刺激性，不如物理防晒安全。敏感肌要注意。

**如何正确涂抹防晒霜？**

防晒霜需要给肌肤吸收的时间，应在出门前10min～20min涂抹，通常建议每2～3个小时涂抹一次。

通常防晒霜在皮肤上涂抹的量为每平方厘米2mg时，才能达到标识的防晒效果。一张脸约需涂抹一枚硬币大小防晒霜，约1g。

长时间接受阳光的照射，建议大家使用SPF30/PA++以上的产品。

大部分防晒霜可以使用洗面奶清洁，不需要卸妆。

**晒伤了怎么办？**

暴晒后易出现红肿，建议先至阴凉处休息，让皮肤充分休息半小时后再用冷水冲或用冷藏过的湿毛巾湿敷20～30分钟，每2～3小时重复一次，以缓解灼热感。

脱皮不要撕、发痒不要挠:很多人晒后的几天里会出现脱皮的情况，**千万！一定！不要用手撕！！！**等它自然脱落，在这期间坚持涂抹低敏的保湿乳霜加快皮肤代谢，让死皮尽快脱落。

如果晒伤部位灼热明显、疼痛、瘙痒，建议及时到医院皮肤科就诊，在专业医生指导下治疗。

**防脱水篇**

在军训过程中，学生会大量出汗，每年都会有许多学生出现全身瘫软无力、下肢乏力等症状，大多数为低钾血症。

**01****什么是低钾血症？**

低钾血症是人体血清钾的浓度<3.5mmol／L（血钾的参考值为3.5-5.5mmol/L，低于3.5表明低血钾，而高于5.5，则属于高血钾）的一种病理生理状态。钾是维持机体细胞内渗透压、酸碱平衡、新陈代谢、神经传导、肌肉以及心肌收缩所必须的一种微量元素。

**02****低钾血症有什么症状呢？**

①低钾血症会刺激神经肌肉系统，使人出现身体疲乏、软弱无力、反应迟钝等症状，严重者会表现为四肢抽搐、全身性肌无力、嗜睡和昏迷、呼吸吞咽困难，甚至窒息。

②部分患者还会伴有口苦、恶心、呕吐、厌食、腹胀、便秘等消化系统症状。

③最危险的后果是影响心脏功能，患者会出现心跳过速、心慌、出冷汗、四肢发凉、血压下降甚至心脏骤停。

一旦运动后出现上述症状，需立即到医院检查治疗。

**03****如何预防低钾血症呢？**

1.生活饮食有规律，不要暴饮暴食或过度饥饿，运动适度，注意劳逸结合。

2.不要过多摄入含碳水化合物高的食物，如米饭，面条，馒头；少吃甜食和糖。

3.在平常训练的休息期间适量补充一些淡盐水。

4.少食含钠高的食物，如油条、油饼、咸肉、火腿、咸鸭蛋、酱油等。

5.多选择含钾丰富的食物，如竹笋、紫菜、黄豆、香蕉、橙子等各种蔬菜水果。

我院急诊科每年都会收治多例军训大量出汗导致的低钾血症学生。急诊科专家提醒各位新生，军训期间要休息好，餐饮要规律，切记不要空腹军训。出汗多时应该注意补钾，尤其是当出现不明原因乏力、心慌时，要警惕低钾血症，立即就医。
